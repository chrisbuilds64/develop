# Was ist ein Kanon? — Erklärvideo, 74 Sekunden

Für Menschen, die das Wort zum ersten Mal hören. Kein Fachbegriff ohne Bild. Gerendert aus `scene.html`
(`node render.mjs`), ohne Sprecher; die Texteinblendungen tragen. Eine vertonte Fassung kann aus derselben Szene
entstehen: die Sätze unten sind der Sprechtext.

| Zeit | Bild | Text |
|---|---|---|
| 0–8 s | Sechs leere, gestrichelte Fächer erscheinen. | Jede Firma hat Regeln. Die meisten stehen nirgends. |
| 8–17 s | Sprechblasen tauchen auf, je mit Kürzel einer Person. | Sie stecken in Köpfen. |
| 17–27 s | Die Blasen fliegen in die Fächer; die Fächer bekommen Namen und werden fest. | Ein Kanon schreibt sie auf. In euren eigenen Worten. |
| 27–38 s | Eine Regelkarte K-01 mit dem Zitat darunter; „Annehmen“ wird gedrückt. | Jede Regel steht auf einem Zitat. Und gilt erst, wenn ein Mensch sie annimmt. |
| 38–46 s | Das Siegel v0.1 fällt auf das Blatt. | Ab jetzt gilt das. |
| 46–55 s | Chat: eine Bitte an den KI-Assistenten, er nennt K-01 und gibt das Tor an Timo. | Auch für eure KI-Assistenten. |

Für jede KI. Lesbar für Menschen, bindend für Maschinen. — Ein Hook beim Start: jedes System liest denselben Kanon, gleich von welchem Anbieter. |
| 66–74 s | Endkarte. | Kanon: das Regelwerk eures Hauses. Der Kanon sagt, was gilt. Hooks erzwingen das Unverhandelbare. Nur Menschen ändern ihn. v0.1 heute — besser nach vier Wochen. |
